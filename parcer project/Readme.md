### 📘 Проект: "Configurable Book Price Monitor"

**Суть:** Скрипт на Python, который собирает данные о книгах с тестового сайта, но **вся логика выбора элементов вынесена в JSON-конфиг**. Пользователь (новичок) меняет конфиг, а не код.

**Целевой сайт:** `http://books.toscrape.com/` (специально создан для тренировки парсеров)

**Стек:** Python, `django`, `requests`, `beautifulsoup4`, `json`, `git`.
